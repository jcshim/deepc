### **1. 핵심 개념 정리 (15분)**

* **`rand()` 사용법**
* `<stdlib.h>`, `<time.h>` 필요
* `srand(time(NULL));` $\rightarrow$ 난수 시드 초기화 (시작 시 1회)
* `(rand() % 6) + 1` $\rightarrow$ 1~6 사이의 난수 생성


* **배열과 카운팅**
* `int count[7] = {0};` $\rightarrow$ 주사위 눈금 1~6을 인덱스 그대로 활용



---

### **2. 핵심 코드 (20분)**

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

// 주사위 던지기 함수
int roll() {
    return (rand() % 6) + 1;
}

int main() {
    int count[7] = {0};
    srand(time(NULL));

    // 주사위 1000번 던지기
    for (int i = 0; i < 1000; i++) {
        count[roll()]++;
    }

    // 결과 출력
    for (int i = 1; i <= 6; i++) {
        printf("[%d] 나온 횟수: %d회\n", i, count[i]);
    }

    return 0;
}

```
