### [문제 1] 숫자야구 판정 로직 (기초 입출력 및 조건문)

* **평가 범위:** 1주차 (변수, 연산자, 조건문)
* **문제:** 정답 숫자 3개(중복 없음)와 사용자가 입력한 숫자 3개가 주어질 때, 볼(Ball)과 **스트라이크(Strike)** 개수를 계산하여 출력하는 프로그램을 작성하시오.
* **조건:**
* 숫자와 위치가 모두 맞으면 Strike, 숫자는 맞지만 위치가 다르면 Ball입니다.
* 3 Strike일 경우 "HOMERUN"을 추가로 출력합니다.


* **입력 예시:** `1 2 3` (정답) / `1 3 5` (입력)
* **출력 예시:** `1 Strike, 1 Ball`

### [문제 2] 아스키 피라미드 패턴 출력 (중첩 반복문)

* **평가 범위:** 2주차 (반복문, 패턴 그리기)
* **문제:** 높이 $N$을 입력받아 중앙 정렬된 피라미드 형태의 문자 패턴을 출력하시오.
* **조건:**
* 홀수 번째 행은 `*`, 짝수 번째 행은 `#`으로 출력합니다.


* **입출력 예시 ($N=4$):**

```text
   *
  ###
 *****
#######

```

### [문제 4] 탐색 및 정렬 성능 비교 (배열, 함수, 정렬/탐색)

* **평가 범위:** 4주차 (qsort, 이진탐색)
* **문제:** 무작위 정수 배열을 입력받아 C 표준 라이브러리의 `qsort()`를 이용해 오름차순 정렬한 후, `bsearch()` 또는 직접 구현한 이진 탐색(Binary Search)을 통해 특정 값의 인덱스를 찾는 코드를 작성하시오.
* **조건:**
* `qsort()`에 필요한 비교 함수 `compare(const void *a, const void *b)`를 올바르게 작성할 것.
* 찾고자 하는 값이 없으면 `-1`을 반환하시오.

### [문제 5] 라이브러리 분할 구현 및 Makefile 빌드 (라이브러리, Makefile, Linux)

* **평가 범위:** 5~7주차 (정적 라이브러리, Makefile, gcc)
* **문제:** 정수 배열의 최댓값과 최솟값을 구하는 유틸리티 라이브러리를 작성하고, 이를 빌드하는 `Makefile`을 작성하시오.
* **조건:**
1. `mymath.h`: 함수 선언 (`int get_max(int arr[], int len);`)
2. `mymath.c`: 함수 구현
3. `main.c`: 라이브러리를 호출하여 결과 출력
4. `Makefile`: `gcc` 명령어를 활용하여 오브젝트 파일(`.o`) 생성 및 최종 실행 파일(`app`)을 빌드하는 자동화 규칙 작성 (`clean` 타겟 포함)
