---

### **1. 핵심 개념 정리 (10분)**

* **선형 탐색 vs 이진 탐색**
* **선형 탐색:** 처음부터 끝까지 순서대로 찾기 ($O(N)$)
* **이진 탐색:** 정렬된 데이터의 가운데를 잘라가며 찾기 ($O(\log N)$) $\rightarrow$ **반드시 사전 정렬 필수**


* **직접 만든 정렬(버블/선택) vs `qsort**`
* 직접 짠 초보적 정렬: $O(N^2)$ (데이터 10만 개 시 약 100억 번 연산)
* C 표준 라이브러리 `qsort()`: 퀵 정렬 기반 $O(N \log N)$


* **시간 측정 헤더:** `<time.h>`의 `clock()` 함수 활용

### **2. 속도 비교 실험 코드 (25분)**

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define N 50000

int a[N], b[N];

// qsort용 비교 함수
int cmp(const void *x, const void *y) {
    return *(int*)x - *(int*)y;
}

// 직접 구현한 선택 정렬 (O(N^2))
void selection_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = i + 1; j < n; j++) {
            if (arr[i] > arr[j]) {
                int t = arr[i]; arr[i] = arr[j]; arr[j] = t;
            }
        }
    }
}

int main() {
    srand(time(NULL));
    for (int i = 0; i < N; i++) a[i] = b[i] = rand();

    // 1. 직접 짠 정렬 시간 측정
    clock_t start = clock();
    selection_sort(a, N);
    printf("직접 짠 정렬(N=%d): %.3f초\n", N, (double)(clock() - start) / CLOCKS_PER_SEC);

    // 2. qsort 시간 측정
    start = clock();
    qsort(b, N, sizeof(int), cmp);
    printf("qsort(N=%d): %.3f초\n", N, (double)(clock() - start) / CLOCKS_PER_SEC);

    // 3. 이진 탐색 (bsearch)
    int target = b[N / 2];
    int *res = (int*)bsearch(&target, b, N, sizeof(int), cmp);
    if (res) printf("이진 탐색 성공: %d\n", *res);

    return 0;
}

```

### **3. 실습 & 실험 포인트 (25분)**

1. **데이터 개수(`N`) 조절 실험**
* `N = 10000` 일 때와 `N = 50000` 일 때의 시간 차이 눈으로 확인하기
* $O(N^2)$ 정렬은 데이터가 5배 늘어나면 시간이 약 25배 폭증하는 현상 확인


2. **탐색 속도 체감**
* 정렬된 배열 `b`에서 `bsearch()`가 얼마나 순식간에 데이터를 찾아내는지 확인
