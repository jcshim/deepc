**[5차시] C언어 정적 라이브러리(.lib) 제작과 활용 (이론 1시간 + 실습 3시간)**

Visual Studio 환경에서 소스 코드를 모듈화하고, 정적 라이브러리(`.lib`) 파일로 묶어 자신만의 유틸리티 함수 모음을 만들어 보는 실무 중심의 강의안입니다.

---

### **1. 이론 수업 (1시간): 라이브러리의 개념과 Visual Studio의 메커니즘**

#### **(1) 라이브러리란 무엇인가? (15분)**

* **필요성:** 매번 함수를 복사·붙여넣기하지 않고, 자주 쓰는 기능을 묶어 재사용하는 방법.
* **소스코드 공개 방지:** 핵심 로직의 구현부(`.c`)는 숨기고 빌드된 결과물(`.lib`)과 사용법이 적힌 헤더 파일(`.h`)만 제공하는 원리.

#### **(2) 정적 라이브러리(.lib) vs 동적 라이브러리(.dll) (15분)**

* **정적 라이브러리(.lib):** 컴파일(링크) 시점에 실행 파일(`.exe`) 내부에 코드가 포함됨. (배포가 쉽지만 파일 크기가 커짐)
* **동적 라이브러리(.dll):** 프로그램 실행 시 메모리에 로드되어 공유됨.

#### **(3) C언어 분할 컴파일 및 링크 과정 (15분)**

* **전처리기(`#include`):** 헤더 파일의 선언부를 복사해옴.
* **컴파일러:** `.c` 파일을 기계어 형태의 `.obj`로 번역.
* **링커:** `.obj`와 외부 `.lib`를 하나로 합쳐 `.exe` 생성.

#### **(4) Visual Studio 프로젝트 구조 이해 (15분)**

* **정적 라이브러리 프로젝트:** 빌드 시 `.exe`가 아닌 `.lib` 생성.
* **프로젝트 간 참조 설정:** 포함 디렉터리(Header path), 추가 라이브러리 디렉터리(Lib path), 추가 의존성 설정 방법.

---

### **2. 실습 수업 (3시간): 나만의 유틸 함수 모음 `myutil.lib` 만들기**

학생들이 직접 2개의 Visual Studio 솔루션/프로젝트를 만들어 완성하는 실습입니다.

#### **[1교시] 정적 라이브러리 프로젝트 생성 및 소스 작성 (50분)**

1. **프로젝트 생성:** `Visual Studio` $\rightarrow$ `새 프로젝트` $\rightarrow$ **C++ 정적 라이브러리(Static Library)** 선택 (프로젝트명: `MyUtils`)
2. **헤더 파일 작성 (`myutil.h`)**
```c
#ifndef MYUTIL_H
#define MYUTIL_H

// 유틸리티 함수 선언
int add(int a, int b);          // 두 수 더하기
int getMax(int a, int b);       // 두 수 중 큰 값 찾기
void printArray(int arr[], int n); // 배열 예쁘게 출력하기

#endif

```


3. **소스 파일 작성 (`myutil.c`)**
```c
#include <stdio.h>
#include "myutil.h"

int add(int a, int b) {
    return a + b;
}

int getMax(int a, int b) {
    return (a > b) ? a : b;
}

void printArray(int arr[], int n) {
    printf("[ ");
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("]\n");
}

```


4. **빌드 수행:** `Ctrl + Shift + B`로 빌드하여 `Debug/` 폴더에 **`MyUtils.lib`** 파일 생성 확인.

---

#### **[2교시] 응용 프로젝트에서 .lib 연결 및 호출 (50분)**

1. **새 프로젝트 생성:** 일반 **C++ 콘솔 앱** 생성 (프로젝트명: `AppTest`)
2. **파일 복사 및 경로 연결 (Visual Studio 설정)**
* `MyUtils` 프로젝트에서 만든 `myutil.h`와 **`MyUtils.lib`** 파일을 `AppTest` 폴더로 복사.
* Visual Studio 설정: `프로젝트 속성` $\rightarrow$ `링커` $\rightarrow$ `입력` $\rightarrow$ `추가 의존성`에 `MyUtils.lib` 입력.
*(또는 코드 상단에 `#pragma comment(lib, "MyUtils.lib")` 작성하는 간단한 방법 안내)*


3. **메인 코드 작성 및 테스트 (`main.c`)**
```c
#include <stdio.h>
#include "myutil.h" // 우리가 만든 헤더 파일 포함

#pragma comment(lib, "MyUtils.lib") // 라이브러리 자동 링크

int main() {
    int a = 10, b = 20;
    int arr[5] = { 1, 3, 5, 7, 9 };

    printf("더하기: %d\n", add(a, b));
    printf("큰 값: %d\n", getMax(a, b));
    printf("배열 출력: ");
    printArray(arr, 5);

    return 0;
}

```

#### **[3교시] 라이브러리 확장 개인 과제 & 디버깅 (50분)**

* **도전 실습 과제:** `MyUtils` 라이브러리에 새로운 유틸 함수 2개를 직접 추가하고 빌드하여 `AppTest`에서 불러오기.
* **추가할 함수 아이디어:**
1. `int isEven(int n)`: 짝수이면 1, 홀수이면 0 반환
2. `void swap(int *a, int *b)`: 두 변수의 값을 서로 바꿈 (포인터 활용)




* **주요 오류 체크 및 정돈:**
* LNK2019 (외부 기호 미해결) 오류 해결법 교육 (`.lib` 링크 미설치 문제)
* C4996 등 빌드 경고 처리 및 C/C++ 구성 환경 맞추기 (x86 / x64 통일)
