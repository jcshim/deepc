[WSL 환경 C언어 Make 및 Makefile 빌드 자동화 가이드]

1. Make와 Makefile이란?

* Make: 소스 코드 파일의 변경 사항을 감지하여 필요한 부분만 선택적으로 재컴파일하는 빌드 자동화 도구
* Makefile: 컴파일 명령, 파일 간의 의존성(Dependency), 빌드 규칙을 정의해 놓은 설정 파일

---

2. Makefile의 기본 구조

[타겟]: [의존성 파일들]
(탭) [실행할 명령]

* 주의: 명령 앞의 공백은 반드시 탭(Tab) 키로 작성해야 함 (스페이스바 사용 시 오류 발생)

---

3. 실습 프로젝트 구조 예시

* 프로젝트 파일 구성: main.c, add.c, sub.c, myheader.h
* 목표: 실행 파일 'app' 생성

---

4. 작성 예시 (Makefile 파일 내용)

# 변수 설정

CC = gcc
CFLAGS = -Wall -Wextra -O2
TARGET = app
OBJS = main.o add.o sub.o

# 기본 타겟 (전체 빌드)

all: $(TARGET)

# 실행 파일 생성 규칙

$(TARGET):$(OBJS)
$(CC)$(CFLAGS) -o $(TARGET)$(OBJS)

# 각 개별 소스 파일 컴파일 규칙

main.o: main.c myheader.h
$(CC)$(CFLAGS) -c main.c

add.o: add.c myheader.h
$(CC)$(CFLAGS) -c add.c

sub.o: sub.c myheader.h
$(CC)$(CFLAGS) -c sub.c

# 생성된 오브젝트 파일 및 실행 파일 삭제

clean:
rm -f $(OBJS)$(TARGET)

---

5. WSL 터미널 실행 명령어

* 빌드 실행:
$ make
* 생성 파일 전체 정리 후 재설정:
$ make clean
* 강제 재빌드:
$ make clean && make
