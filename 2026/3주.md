#### **4교시: 종합 실습 - 주사위 시뮬레이터 프로젝트**

* **실습 과제 (40분)**
* **주제:** 주사위를 1,000번 던졌을 때 각 눈금($1 \sim 6$)이 나온 횟수와 확률 계산하기
* **핵심 포인트:**
1. 각 눈의 출현 횟수를 카운트할 크기 6(또는 7)의 배열 사용
2. 주사위를 던지는 로직을 `roll_dice()` 함수로 분리
3. 결과를 깔끔하게 출력하는 `print_result()` 함수 구현




* **정리 및 Q&A (10분)**
* 배열 인덱스 초과(`Out of Bounds`) 오류 피드백
* `srand()` 위치 관련 주의사항(루프 안이 아닌 `main` 시작 시 1회 호출)



---

### **[4교시 프로젝트 정답 C언어 코드]**

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int roll_dice() {
    return (rand() % 6) + 1;
}

int main() {
    int count[7] = {0}; // 1~6 번 인덱스 사용
    int total = 1000;

    srand(time(NULL));

    for (int i = 0; i < total; i++) {
        int num = roll_dice();
        count[num]++;
    }

    printf("=== 주사위 1,000회 시뮬레이션 ===\n");
    for (int i = 1; i <= 6; i++) {
        printf("[%d] 나온 횟수: %3d회 (확률: %.1f%%)\n", 
                i, count[i], (float)count[i] / total * 100);
    }

    return 0;
}

```
